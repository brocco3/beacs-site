# The Beacs / Cloudflare Pages starter

## 公開方法
1. このフォルダをGitHubリポジトリにアップロード
2. Cloudflare Dashboard > Workers & Pages > Create > Pages > Connect to Git
3. Framework preset: None
4. Build command: 空欄
5. Build output directory: /
6. Deploy
